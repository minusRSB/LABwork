# LABwork  
Лабораторный проект студента Кушхова Амира, 2025 г.

## О проекте

Проект посвящён построению end-to-end пайплайна анализа видеоданных для отслеживания движения объекта, извлечения временных характеристик и прогнозирования траектории с использованием методов computer vision, signal processing и sequence modeling.

В качестве тестового сценария используется синтетическая модель маятника, позволяющая проверить корректность алгоритмов в контролируемой среде до переноса подхода на реальные видеоданные.

## Задачи проекта

- Реализовать автоматическое извлечение координат объекта из видеопотока  
- Построить временной ряд движения  
- Выделить основные динамические характеристики сигнала  
- Применить sequence-модель для краткосрочного прогнозирования траектории  
- Сравнить вычисленные параметры с теоретической моделью для валидации пайплайна  

## Что реализовано

- Генерация синтетического видеодатасета  
- Frame-by-frame обработка видео  
- Детекция объекта через контурный анализ  
- Извлечение координат движения  
- Анализ временного сигнала:
  - период  
  - частота  
  - амплитуда  
  - спектральные характеристики  
- Построение фазового пространства  
- Автокорреляционный анализ  
- Обучение LSTM-модели для предсказания следующего положения объекта  
- Оценка ошибки модели по MSE и MAE  
- Экспорт результатов анализа в JSON  
- Генерация аннотированного видео с наложением траектории

## Архитектура пайплайна

### Data Generation

Синтетическое видео формируется с заранее заданными параметрами движения, что позволяет использовать контролируемый benchmark для тестирования алгоритма.

### Computer Vision Processing

Для каждого кадра выполняются:
- grayscale conversion  
- Gaussian blur  
- thresholding  
- contour detection  

### Feature Extraction

Из видео извлекаются координаты объекта, формирующие временной ряд для последующего анализа.

### Signal Analysis

Для временного ряда рассчитываются:
- peak detection  
- detrending  
- spectral density  
- autocorrelation  
- phase portrait  

### Predictive Modeling

Для последовательностей координат формируются sliding windows, на которых обучается LSTM-модель для next-step prediction.

### Validation

Результаты сравниваются с теоретической моделью движения, что позволяет оценить корректность реализации.
